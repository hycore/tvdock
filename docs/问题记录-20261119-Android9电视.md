# 问题记录 · Android 9 小米电视除广告(2026-11-19)

> 设备:小米电视 MiTV-ASTP0(Android 9 / SDK 28)· IP 192.168.1.4
> 场景:用户要求"除广告"(对应 skill 温和优化套餐)
> 复盘人:AI 执行会话

## 问题 1:tv_ads_off.sh 全部 13 项失败——`pm block` 在新系统上不存在

- **现象**:`pm block <包名>` 返回 `Unknown command: block`,13 个广告组件全部冻结失败
- **根因**:`pm block` 只存在于旧版 MIUI TV(Android 4.4 时代);本机是 **Android 9(SDK 28)**,该子命令已被移除
- **影响面**:skill 原按"MIUI TV 1.3.x / Android 4.4.4"设计,在新系统上整个脚本失效
- **修复**:tv_ads_off.sh 重写为版本感知三级降级链:
  `pm block(SDK<24)→ pm suspend(SDK≥24)→ pm uninstall --user 0(持久)→ pm disable-user --user 0`
  每级执行后验证,验证通过即冻结成功
- **实证**:Android 9 模拟器/实机均通过;最终实机结果见问题 4

## 问题 2:`pm suspend` 收起后**重启不持久**

- **现象**:suspend 报告成功的 5 个组件,电视重启后全部恢复(uninstall --user 0 的组件则保持移除)
- **根因**:小米电视启动阶段会恢复/重装部分系统组件,suspend 状态未持久化
- **修复**:确认广告组件一律改用 `pm uninstall --user 0`(用户级卸载,**重启持久**);可随时 `cmd package install-existing <包名>` 找回
- **实证**:8 个用户级卸载的组件,重启后 8/8 保持移除 ✓

## 问题 3:/vendor 分区包受保护,suspend/disable 均拒绝

- **现象**:部分包(如 com.miui.systemAdSolution)位于 /vendor 分区,suspend 与 disable-user 均报权限拒绝
- **修复**:`pm uninstall --user 0` 对 /vendor 包同样生效(隐藏用户副本)
- **边界**:系统分区文件仍在;电视恢复出厂或 OTA 会回归——届时重跑本 skill 即可

## 问题 4:开机广告移除后仍偶发——漏网组件 + 复活组件

- **排查**:重启后逐项核对,8 个用户级卸载全部持久 ✓;但 5 个 suspend 收起的组件复活,复活组件在被清理前的启动窗口播了推广
- **修复**:复活的 5 个一并转为用户级卸载;再加一轮全量深查,又发现 4 个漏网遥测/推送组件(miui.analytics / tvpush / healthdiagnosis / cloudcontrol)一并移除
- **最终**:16 个广告/遥测组件全部清零,后台进程级复验干净

## 问题 5:AdGuard 私人 DNS(DoT)整机屏蔽在大陆网络不可达

- **现象**:`private_dns_mode=hostname` + `dns.adguard.com` 后,电视**所有**域名解析失败(baidu 也 unknown host)
- **根因**:大陆网络到 AdGuard DoT 不通
- **处置**:立即回滚(`private_dns_mode off`),网络恢复
- **替代方案**:广告域名屏蔽改走**路由器端**(域名清单已生成:`docs/广告域名清单-路由器DNS屏蔽.txt`,含 AdGuard Home/OpenWrt 配置方法)

## 问题 6:/etc/hosts 只读,本机 hosts 屏蔽不可行

- **实测**:`/etc/hosts` 属 root 所有,系统分区只读挂载;`adb root` 在生产固件被拒("adbd cannot run as root in production builds")
- **结论**:非 root 电视本机 hosts 方案不可行,同问题 5 走 DNS 层替代

## 遗留与建议

1. gamecenter / upgrade 两个组件被电视开机流程**自动重装**——如再次出现,重跑本 skill 即可;根治需路由器 DNS 屏蔽上游下载源
2. 待机屏保(com.xiaomi.mibox.lockscreen)本机未预装,未涉及
3. 下次开机仍见推广时:注意区分**系统层**(已清)与 **App 内业务广告**(如奇异果贴片,属爱奇艺服务端,客户端无法去除)
